# Vyshnavi Birthday Website

Open `index.html` in a browser, or upload this folder to GitHub Pages.

The design is a cute handmade birthday scrapbook theme with paper crafts, crayons, tape, hearts, polaroids, a memory camera, and a love-letter page.

## Add Photos

Put the real photos in the `assets` folder with these exact names:

- `letter-photo-1.jpg` - floral top selfie
- `letter-photo-2.jpg` - pink hoodie phone pic
- `memory-1.jpg`
- `memory-2.jpg`
- `memory-3.jpg`
- `memory-4.jpg`
- `memory-5.jpg`
- `memory-6.jpg`

The six memory photos are for the camera gallery: the purple `OVER` tee and gray striped top candid shots.

Extra photos are included as `moment-1` through `moment-7` in the "More of her" section.

## Edit The Message

Open `index.html` and change the letter text inside the `letter-paper` section.
